# Trabajo Práctico 4: El Método equals() y hashCode() en Java
**Materia:** Programación III  
**Carrera:** Tecnicatura Universitaria en Programación a Distancia (UTN)

## Objetivo General
Entender cómo funciona el método `equals()` en Java para comparar el contenido de los objetos en lugar de sus referencias, y aprender a sobrescribirlo junto con `hashCode()` siguiendo el contrato de igualdad.
