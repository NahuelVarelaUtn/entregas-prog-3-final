# Trabajo Práctico - Colecciones (List y ArrayList) en Java
**Materia:** Programación III  
**Carrera:** Tecnicatura Universitaria en Programación a Distancia (UTN)

## Descripción
Se implementa la clase `Alumno` con los atributos `nombre` y `nota`, sobrescribiendo `toString()`. En `Main` se almacenan instancias en un `ArrayList` y se recorren con un bucle `for-each`, verificando el orden de inserción y la posibilidad de almacenar duplicados.

## Compilación y ejecución
```bash
javac -d bin src/tp2colecciones/Alumno.java src/tp2colecciones/Main.java
java -cp bin tp2colecciones.Main
```
