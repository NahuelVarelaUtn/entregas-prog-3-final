# Trabajo Práctico 2 - Colecciones (Set y HashSet) en Java
**Materia:** Programación III  
**Carrera:** Tecnicatura Universitaria en Programación a Distancia (UTN)

## Descripción
Se implementa la clase `Producto` con los atributos `codigo` y `descripcion`, sobrescribiendo `equals()` y `hashCode()` basándose en `codigo`. En `Main` se almacenan productos en un `HashSet`, verificando que no se permitan elementos duplicados y asegurando la unicidad.

## Compilación y ejecución por consola
```bash
javac -d bin src/tp3colecciones/Producto.java src/tp3colecciones/Main.java
java -cp bin tp3colecciones.Main
```
