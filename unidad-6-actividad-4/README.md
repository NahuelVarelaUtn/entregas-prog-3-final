# Trabajo Práctico - Colecciones (Map y HashMap) en Java
**Materia:** Programación III  
**Carrera:** Tecnicatura Universitaria en Programación a Distancia (UTN)

## Descripción
Se implementa la clase `Curso` con los atributos `nombre` y `docente`, sobrescribiendo `toString()`. En `Main` se utiliza un `HashMap<String, Curso>` usando el código del curso como clave, se recupera un curso por clave mediante `get()` y se recorren todas las entradas clave-valor con `entrySet()`.

## Compilación y ejecución por consola
```bash
javac -d bin src/tp4colecciones/Curso.java src/tp4colecciones/Main.java
java -cp bin tp4colecciones.Main
```
